# LaMa-inpainting: 2D ocean T/S sections | Baltic Sea

## Постановка задачи

```
Вход  (4, NZ, NX):  [field | mask_ctd | mask_cmems | bathymetry]
                         │         │          │
                    CTD-линии  CMEMS-точки  батиметрия
                    (вертикаль) (квази-рег.  (нормир.)
                                нараст. шаг)
Выход (1, NZ, NX):  плотное поле T ∈ [0,1]
```

**CTD** → вертикальные линии (сплошное покрытие по z до дна, высокая точность).  
**CMEMS** → разреженная квази-регулярная сетка: `np.logspace` по z (плотнее у поверхности), равномерно по x. Имитирует стандартные уровни реанализа.  
Задача сети — совместить оба источника и заполнить пустой разрез.

---

## Почему GAN отключён

| Критерий | GAN (PatchGAN) | Без дискриминатора |
|---|---|---|
| Время обучения | ×2 | базовое |
| Стабильность | нестабилен при малых данных | стабилен |
| Нужность для T/S | нет (поля гладкие) | — |
| Физ. ограничения | конфликт с adv. loss | чистая оптимизация |

GAN включается позже как ablation study при доступе к большому GPU.

---

## Физические штрафы (§1.1)

| Потеря | Формула | Смысл |
|---|---|---|
| L_stab | ReLU(∂T/∂z) на коллок. точках | ∂ρ/∂z ≥ 0 |
| L_bbl  | (∂T/∂z)² у дна | гомогенизация BBL |
| L_grad | изотропная TV | подавление артефактов |

Производные через центральные разности (без AD — достаточно для дискретных полей).
